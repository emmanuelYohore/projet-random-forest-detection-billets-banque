# projet-random-forest-detection-billets-banque
Ce projet présente l'utilisation de l'algorithme Random Forest avec Scikit-learn pour détecter automatiquement les faux billets de banque à partir de caractéristiques statistiques extraites d'images (variance, asymétrie, curtosis, entropie). Le notebook montre l'exploration des données jusqu'à l'optimisation des hyperparamètres
